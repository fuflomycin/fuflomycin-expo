# Справочник «Фуфломицины»

Русскоязычный справочник препаратов с недоказанной эффективностью, гомеопатии и негативного перечня Формулярного комитета. Это не источник персональных медицинских рекомендаций.

## Выкладка

Управление выкладкой состоит из трёх действий.

**Сборка.** Пуш в любую ветку, кроме `main`, собирает подписанный release-APK. Файл остаётся артефактом Actions и публикуется prerelease `fuflomycin-<versionName>-<короткий sha>` с тегом `apk-<короткий sha>`. Текст prerelease — первая строка сообщения коммита. `versionCode` этой сборки берётся из Gradle и держится на линии, которую уже знает Play. В Play сборка не отправляется.

**Выкладка.** Любое попадание коммита в `main` собирает AAB и публикует его на дорожку закрытого тестирования. Релиз сразу доступен тестировщикам этой дорожки. `versionCode` — наибольший код, который уже есть в Play, плюс один; в git он не записывается. `versionName` остаётся строкой из Gradle.

**Перенос.** В прод эту версию переносит человек в Play Console.

Ключ выкладки — сервисный аккаунт `fuflomycin@fuflomycin-android.iam.gserviceaccount.com`. Ролей в Google Cloud у него нет. В Play Console у него одно право на приложение `com.fuflomycin_rn`: выпуск на тестовые дорожки. Список тестировщиков ведёт человек. Ключ лежит в окружении GitHub `play-closed`, и это окружение принимает только ветку `main`.

## Локальная сборка

Нужны Node.js 22, JDK 17 и Android SDK с платформой 37. Каталог SDK Gradle берёт из `android/local.properties` (`sdk.dir`) или из `ANDROID_HOME`.

Подключите устройство или запустите эмулятор с API не ниже 24, затем из корня репозитория:

```bash
npm ci
cd android && ./gradlew :app:installDebug
```

Перед компиляцией Gradle сам собирает список препаратов из `cards/`. Debug-сборка подписывается отладочным ключом Android. Upload-ключ Play использует только Actions.

Проверка компилятора карточек:

```bash
npm test
```

## Карточки

Карточка — файл Markdown. Имя файла в kebab-case, по нему строится идентификатор препарата. Каталог задаёт категорию, а поле `section` — строку, которую Справочник показывает на карточке:

| Каталог | `section` |
| --- | --- |
| `cards/homeopathy` | `Гомеопатия` |
| `cards/rsp` | `РСП / Фуфломицин` |
| `cards/fk` | `Негативный перечень ФК` |

```yaml
---
title: Название
label: orange
section: РСП / Фуфломицин
source: https://encyclopatia.ru/wiki/Пример
other:
  - Другое имя
gallery:
  - rsp-primer.png
mnn: вещество
---

Текст карточки пишется Markdown под шапкой.
```

Обязательны `title` и ярлык `label`: `red`, `orange` или `yellow`. Дальше идут `section`, `source`, список синонимов `other` и список кадров `gallery`. Поле `mnn` необязательно.

Кадр — файл jpg, jpeg, png или webp внутри `cards/`. В `gallery` пишется только имя файла. Имя уникально во всём `cards/`.

Нет `title` или ярлык вне трёх значений — карточка молча не попадает в список. Нет файла кадра — сборка списка падает: её запускают `npm run build:list` и Gradle перед компиляцией. `npm test` проверяет этот отказ на временных карточках.

Новая или изменённая карточка доходит до человека только со следующей версией Справочника. Уже установленная версия список по сети не обновляет.
