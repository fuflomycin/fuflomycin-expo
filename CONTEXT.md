# Расстрельный список препаратов

Русскоязычный список препаратов с недоказанной эффективностью. Гомеопатия и Негативный перечень ФК входят в него как дополнение. Это не источник персональных медицинских рекомендаций.

## Language

**РСП**:
Имя продукта и категория вердикта. Полное имя продукта — «Расстрельный список препаратов». На карточке категория пишется «РСП / Фуфломицин».
_Avoid_: Справочник, приложение, фуфломицины (как имя продукта)

**Дополнение**:
Категория, которая входит в РСП помимо категории РСП: Гомеопатия или Негативный перечень ФК.
_Avoid_: дополнительный список

**Иконка РСП**:
Значок РСП на домашнем экране.
_Avoid_: иконка справочника, иконка приложения, app icon, логотип, ярлык (как имя этого значка)

**Подпись иконки**:
Текст «Фуфломицины» под иконкой РСП на домашнем экране.
_Avoid_: имя продукта

**Препарат**:
Именованная единица РСП, которую ищет человек: название, синонимы, категория, ярлык.
_Avoid_: Drug, фуфломицин (как единица данных)

**Карточка**:
Markdown-исходник одного препарата.
_Avoid_: файл, документ, статья

**Категория**:
Один из трёх источников происхождения вердикта: РСП, Гомеопатия, Негативный перечень ФК.
_Avoid_: section, раздел, список (как имя категории)

**Ярлык**:
Цветовая метка вердикта на препарате.
_Avoid_: label, цвет

**Синоним**:
Другое имя того же препарата.
_Avoid_: other, alias, otherstr

**МНН**:
Международное непатентованное наименование вещества у препарата. Есть не у всех.
_Avoid_: INN, generic, действующее вещество (как имя этого поля)

**Поиск по МНН**:
Поиск МНН препарата в Cochrane или Pubmed. Есть только у препарата с МНН.
_Avoid_: поиск по базам, источник

**Галерея**:
Изображения препарата. Может быть пустой. Отдельного «главного» изображения нет.
_Avoid_: photo, фото, cover, обложка, gallery, слайды, главное изображение

**Список препаратов**:
Набор препаратов, который РСП показывает человеку. В короткой форме — список.
_Avoid_: снимок, бандл, дамп, каталог

**Источник**:
URL внешнего основания карточки.
_Avoid_: source

**О РСП**:
Экран с дисклеймером, объяснением РСП и дополнений, легендой и поддержкой.
_Avoid_: О справочнике, О программе, Info, About

**Легенда**:
Расшифровка аббревиатур из карточек; стоит на экране «О РСП». Не объясняет ярлыки.
_Avoid_: legend, ключ цветов
