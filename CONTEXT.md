# Справочник «Фуфломицины»

Русскоязычный справочник препаратов с недоказанной эффективностью, гомеопатии и негативного перечня Формулярного комитета. Это не источник персональных медицинских рекомендаций.

## Language

**Справочник**:
Продукт: клиент Expo (Android, iOS, web) и его набор препаратов.
_Avoid_: приложение, PWA, app, клиент (как имя продукта)

**Иконка справочника**:
Значок Справочника на домашнем экране и во вкладке браузера.
_Avoid_: иконка приложения, app icon, логотип, ярлык (как имя этого значка)

**Препарат**:
Именованная единица справочника, которую ищет человек: название, синонимы, категория, ярлык.
_Avoid_: Drug, фуфломицин (как единица данных)

**Карточка**:
Markdown-исходник одного препарата.
_Avoid_: файл, документ, статья

**Категория**:
Один из трёх источников происхождения вердикта: Гомеопатия, РСП, Негативный перечень ФК.
_Avoid_: section, раздел, список (как имя категории)

**Ярлык**:
Цветовая метка вердикта на препарате.
_Avoid_: label, цвет

**Синоним**:
Другое имя того же препарата.
_Avoid_: other, alias, otherstr

**МНН**:
Международное непатентованное наименование вещества у препарата. Есть не у всех.
_Avoid_: INN, generic, действующее вещество (как имя этого поля)

**Галерея**:
Изображения препарата. Может быть пустой. Отдельного «главного» изображения нет.
_Avoid_: photo, фото, cover, обложка, gallery, слайды, главное изображение

**Список препаратов**:
Набор препаратов, который Справочник показывает человеку. В короткой форме — список.
_Avoid_: снимок, бандл, дамп, каталог

**Источник**:
URL внешнего основания карточки (реестр, РСП, перечень ФК).
_Avoid_: source

**О справочнике**:
Экран с дисклеймером, тремя категориями, легендой и поддержкой.
_Avoid_: О программе, Info, About

**Легенда**:
Расшифровка аббревиатур из карточек; стоит на экране «О справочнике». Не объясняет ярлыки.
_Avoid_: legend, ключ цветов
