# Страница Google Play

Тексты основной страницы `com.fuflomycin_rn`. В Console их копирует человек.

## Краткое описание

РСП без доказанной эффективности, плюс Гомеопатия и Негативный перечень ФК

## Полное описание

Расстрельный список препаратов (РСП) сформирован по отсутствию убедительных данных об эффективности по заявленным показаниям и по отсутствию в авторитетных источниках. Дополнительно в него входят Гомеопатия и Негативный перечень ФК. В списке ищут препарат по названию, синониму или МНН и открывают карточку с вердиктом. Это не источник персональных медицинских рекомендаций.

## Кадры

Четыре скриншота телефона, 1080×1920, светлая тема, без подписей поверх. Снимает и заливает в Console человек, со сборки, где экран «О РСП» уже с новым текстом. Заголовок страницы Play, графический объект и значок не меняются.

1. Список с пустым запросом, верх: счётчик «Препаратов: …», рядом Арбидол.
2. Карточка Арбидола сверху: галерея, оранжевый ярлык, строка «РСП / Фуфломицин», начало текста.
3. Та же карточка, прокрутка до блока МНН.
4. «О РСП» без прокрутки: дисклеймер и дополнение.
