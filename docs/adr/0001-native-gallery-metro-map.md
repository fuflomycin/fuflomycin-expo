# Native-пол галереи — сгенерированная Metro-карта `require()`

Спека кладёт кадры в `public/img/` и запрещает каталог ассетов Expo как канон; на native `public/` не становится `source` для `Image`, поэтому офлайн-пол этой сборки пустой. Канон и web по-прежнему `/img/<имя>`; native дополнительно получает gitignored-модуль `.native.ts` из `build:list`: те же имена, что копируются в `/img/`, `require()` на файлы в `cards/`. Вшитое имя → модуль ассета, неизвестное → `https://<origin>/img/<имя>`. Web карту не импортирует, иначе ~17 МБ уедут во фронт поверх `dist/img/`.

Плагин `expo-asset` по resource name отвергли: имена с дефисами ломаются в Android `res/`. Копирование в platform `assets/` отвергли: два нативных пайплайна ради той же дыры.
