# Закрытое тестирование при пуше в main

Справочник собирает GitHub Actions. Пуш в ветку, кроме `main`, кладёт подписанный release-APK в артефакты и в Play не отправляет. Пуш в `main` собирает AAB и выкладывает его на дорожку закрытого тестирования (`alpha`) со статусом `completed`. `versionCode` этой выкладки — наибольший код уже в Play плюс один, в git он не пишется; `versionName` остаётся строкой из Gradle. В прод Actions не публикует: туда релиз переносят руками, поэтому новая карточка доходит до тестировщиков дорожки с этим пушем, а до человека на проде — только после переноса.

## Considered Options

- Собирать APK и на `main`, вместе с AAB.
- Брать `versionCode` из числа коммитов или из номера прогона Actions.
- Выкладывать на внутреннее тестирование или сразу в прод.

## Consequences

- Пока сервисный аккаунт не приглашён к `com.fuflomycin_rn`, выкладка с `main` получает отказ Play.
- APK с ветки носит `versionCode` из Gradle, чтобы не оказаться выше линии Play: иначе обновление с закрытого тестирования поверх такого APK не встанет.
