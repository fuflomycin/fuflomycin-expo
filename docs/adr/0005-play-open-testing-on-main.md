# Открытое тестирование при пуше в main

Пуш в `main` собирает AAB и выкладывает его на дорожку открытого тестирования (`beta`) со статусом `completed`. Закрытое тестирование (`alpha`) пайплайн больше не обновляет: последний релиз там остаётся, пока его не снимут в Play Console. Окружение GitHub называется `play-open` и принимает только `main`. Сборка становится доступна после проверки Play; войти может любой по ссылке opt-in. `versionCode`, заметка релиза, ручной перенос в прод и prerelease APK с остальных веток остаются как в ADR 0003. Сменяет ADR 0003.

## Considered Options

- Остановить текущий релиз на `alpha` из того же прогона. Play тогда снова отдаёт предыдущий completed, а при единственном релизе остановка может не пройти.
- Оставить окружение `play-closed`. Имя перестало бы совпадать с дорожкой.

## Consequences

- До первого пуша в `main` человек заводит окружение `play-open`, переносит секреты и ограничивает деплой веткой `main`.
- Люди из списка закрытого тестирования новую сборку не получают, пока не войдут в открытое.
- `versionCode` по-прежнему максимальный код Play плюс один, поэтому открытая сборка встаёт поверх оставшегося релиза `alpha` и прода.
- APK с ветки по-прежнему носит `versionCode` из Gradle, ниже линии Play.
